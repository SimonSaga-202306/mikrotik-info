## 八、3 步跟进计划（R54，**最多 3 次**）

> 综合客户官网/公开资料与我方（Saga/SmartByte）型号与能力矩阵得出；**只做 3 次**，每次推进一个台阶，第三次后要么出单、要么降频。

### 第 1 次跟进 · 类目空缺提案（工业宽温 DIN PoE）

- **推什么**：LT-IS6310G-2GX8GT PoE 版（8G + 2×2.5G SFP，DIN，-40~75°C）
- **切入点**：你货架上 Allied 无工业宽温：宽温 DIN PoE 做补位 SKU——网店挂位提案。
- **要问的问题**：工业宽温 PoE 这个类目你们网店还空着——挂位怎么谈？
- **随附证明**：类目空缺说明 + 分销价目 + 宽温报告（德文）。

### 第 2 次跟进 · 24 口 CCTV/PoE（商用高段位补位）

- **推什么**：LT-S8328GP-4GX24GT-S（24×千兆 PoE++ + 4×万兆上行）
- **切入点**：PoE++ 大功率+4×10G 上行档位：与 Allied 同档商用高段位作补位价。
- **要问的问题**：客户要大功率 PoE++ 时另一个选项要不要？
- **随附证明**：规格对照 + 梯价（德文）。

### 第 3 次跟进 · 管理型 PoE（项目第二来源）

- **推什么**：LT-IS6312XG-4XS8GT（8G + 4×SFP+ 10G，PoE 版）
- **切入点**：项目第二来源：管理型（ERPS/L3）当客户比价时的备选报价。
- **要问的问题**：项目比价的第二来源报价要不要挂？
- **随附证明**：VLAN/ERPS 速查 + 第二来源价目（德文）。
