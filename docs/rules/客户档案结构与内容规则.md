## 二、内容纪律（硬性）

1. **单一产品决策**：首触只推 P1，备选不进邮件；3 步计划/概览/邮件口径必须一致。Saga 暂无规格的口子（商用 PoE bt 90W / 全万兆汇聚 / 8 口商用 10G 上联）**不得**现编型号，沿用旧对照并显式标注。
2. **价格口径**：一律 `$xx USD EXW（YYYY-MM-DD 快照，15 天有效，报价前核价）`；不写裸 `$`（对非美元客户有数量级歧义）。
3. **邮箱验证口径**：MX/DNS 级核验；沙箱 SMTP RCPT 不可达如实标注（用户 2026-09-28 已确认：验证不了就算了、标注出来即可）。退信即停用该猜测邮箱。
4. **首触邮件**：一次只问一个问题；商业语言（少上门/回本周期）优先，技术参数只在有信号后展开；不提「我研究过你官网」；不出现「Made in China」。
5. **事实分层**：CSV 备注行 ≠ 官网证实；未验证场景（如 A-002 的农业/电网/音乐节）标【假设】，先问后推。
6. **教师/公立红线**：培训师户只谈本人教学硬件与自有工程，不打学员名单、不经培训语境推销；公立雇员只谈私人/自费语境。
7. **停止开发条件**：3 次定向触达无实质回复 / 现用平台完全满足 / 只愿比价 / 决策者接触不到 / 书面拒绝——命中即停（时间=成本）。
8. **R32 小国**：塞尔维亚等低投入国档案照建、外联降级，档案内注明依据。
9. **位置/编号冻结**：A-001 起顺位永不动，只改内容（R37/R49/R54 纪律延续）；结构化档案 v2 只是内容重排。

## 三、外审意见处理台账（采纳/压缩/弃）

- **采纳**：型号冲突清零；事实/推断/假设；一页摘要→SALES BRIEF；价格币种；邮件重写；成功/退出标准；Qualification；Unknowns；停止条件；跟进表加列；团队描述统一；死链口径；竞品共存问法；structured_profile。
- **压缩采纳**：机会矩阵/风险评分/客户旅程/时间轴 → 并入 SALES BRIEF 与 Unknowns 的行内表达，不单开节；SWOT 保留下沉。
- **弃**：Obsidian 全库双链（现阶段过度工程，用 `profile/检索目录.md` 标签维度替代）；B/C 同步重构（旧纪律「暂时不管 B 和 C」）；评分卡星级全套（只留 volume_potential / risk_flags 两项进 YAML）。
