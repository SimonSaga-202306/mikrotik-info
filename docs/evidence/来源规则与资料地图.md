# 来源规则与资料地图

记录日期：2026-09-27。对应用户要求：总账U18–U20。

## 一、什么算证据

| 分类 | 能证明什么 | 不能自动证明什么 |
|---|---|---|
| 官网正文/官方PDF | 指定日期该页面写了该字段；需匹配公司/地区/税号 | 投递成功、人员仍在职、采购权、客户愿意采购 |
| 厂商/协会伙伴目录 | 名录中列了该伙伴及字段 | 每个该品牌型号都用Prestera、认证仍有效、对手愿意换货 |
| 企业自营社媒/店铺 | 企业在该入口披露的信息；须先匹配实体 | 第三方员工资料的完整真实性 |
| 第三方目录 | 目录完整公开了联系方式 | 公司当前确认、当前邮箱可投递 |
| 仅搜索索引/缓存 | 搜索引擎曾返回该文本 | 页面现在仍存在。实际404时必须明确标注 |
| 本地原始附件 | 该文档/版本/单元格的供应商声明 | 现行报价、全部SKU通用、第三方实测 |
| CSV / batch / Git | 数据从何处进入仓库、如何变化 | 原始业务事实是真实的 |
| Agent策略/话术/评级 | 内部分析和代码推导 | 客户已经确认的痛点/采购需求/产品参数 |

**只存URL还不够：**要记录对应字段、摘录、身份匹配、检索日期、来源类型、验证限制。没有证据只能标“待补证”。资料日期、检索日期、记录日期和用户发言日期不得混为一谈。
